# exports/

Carpeta de trabajo personal. Todo lo que pongas acá (menos este archivo) está ignorado por Git.

Usala para:

- Guardar exportaciones propias (Excel, CSV, PDF, lo que sea) generadas a partir de los datos.
- Dejar bases de trabajo, recortes o pruebas mientras analizás algo.
- Cualquier archivo que no quieras versionar por error.

Los scripts del repositorio no leen ni escriben acá automáticamente: es solo un lugar convenido para no mezclar archivos personales con `Data/`, que es donde viven el código y las salidas propias del pipeline.
