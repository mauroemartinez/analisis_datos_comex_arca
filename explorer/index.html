Ejemplos
  • Un importador: SELECT * FROM impo WHERE upper(NOMBRE_IMPORTADOR) LIKE '%ROCHE%' LIMIT 200
  • Por NCM: SELECT PERIODO, sum(FOB_TOTAL_USD) FROM impo WHERE POS_NCM LIKE '8504%' GROUP BY 1 ORDER BY 1
  • Rango de fechas: SELECT * FROM impo WHERE PERIODO BETWEEN '202301' AND '202312' LIMIT 200

Gracias a que el histórico está ordenado por PERIODO, filtrar por rango de fechas evita leer la mayoría del archivo (poda de row groups por estadísticas min/max de Parquet), aunque el archivo entero pese varios GB.
